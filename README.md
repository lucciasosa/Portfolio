# Lucía Sosa — Portfolio UGC

Landing page responsive reconstruida a partir del PDF original de Lucía Sosa.

## Incluye
- Los textos, fotografías personales, imágenes de contenido, recursos de herramientas y logotipos extraídos del PDF aportado.
- Diseño editorial inspirado en la estética parisina de moda/beauty: rosa, crema, rojo cereza, tipografía serif, collage fotográfico y detalles decorativos.
- Secciones: presentación, sobre mí, herramientas, ejemplos de contenido, marcas y contacto.
- Adaptación para móvil y escritorio.
- HTML/CSS/JS estáticos, sin proceso de compilación.

## Ver localmente
Abre `index.html` en el navegador. Para publicar, sube la carpeta completa manteniendo `assets/`.

## Publicar gratis en Netlify
1. Descomprime el ZIP.
2. Abre https://app.netlify.com/drop
3. Arrastra la carpeta `lucia-site`.
4. Netlify te dará una URL pública.

También puedes subir los archivos a GitHub Pages o cualquier hosting estático.
